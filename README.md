# PHP and MySQL Docker Compose Project

Този проект демонстрира контейнеризация на PHP CLI приложение, което комуникира с MySQL база данни, използвайки Docker Compose.

## Структура на проекта
- `compose.yml` - Дефинира и свързва услугите (`app` и `db`).
- `app/Dockerfile` - Конфигурира изображението за PHP приложението с нужните разширения (pdo_mysql).
- `app/script.php` - Основният скрипт, който тества връзката с базата данни.

## Компоненти и комуникация
1. **Услуга `db` (MySQL 8.0):** Стартира база данни с автоматично създадено потребителско име, парола и схема.
2. **Услуга `app` (PHP CLI):** Изчаква стартирането на базата данни и прави сигурна връзка през PDO. Комуникацията между услугите е осъществена чрез вградената Docker мрежа, като PHP използва хост името `db`.

## Как се изграждат и стартират контейнерите
За стартиране на проекта изпълнете следната команда в коренната директория:
```bash
docker compose up --build
docker compose up --build
```
